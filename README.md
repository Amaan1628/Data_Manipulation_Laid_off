# MySQL Layoffs Exploratory Data Analysis

📌 Project Overview
This project uses **MySQL** to perform Exploratory Data Analysis (EDA) on a layoffs dataset.

The analysis focuses on identifying patterns in employee layoffs over time and examining which companies recorded the highest number of layoffs across different years.

🛠️ Tools Used
* MySQL
* MySQL Workbench
* SQL


🧠 SQL Concepts Demonstrated

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* `SUM()`
* `SUBSTRING()`
* `YEAR()`
* Common Table Expressions (CTEs)
* Window Functions
* `SUM() OVER()`
* `DENSE_RANK()`
* `PARTITION BY`
* Aggregation
* Data grouping and ranking

## 📊 Key Questions Explored

The project explores questions such as:

* How did total layoffs change month by month?
* What was the cumulative number of layoffs over time?
* Which companies had the highest total layoffs?
* How many employees did each company lay off in each year?
* Which companies ranked highest in layoffs during each year?
* Which companies were among the top 5 for layoffs in each year?
